# Vehicle Inventory & Booking API

A Vehicle Inventory and Booking REST API built using Django and Django REST Framework.
The project allows users to manage vehicles, create vehicle bookings, validate booking dates and customer information, calculate booking prices automatically, and prevent overlapping bookings.

## Features

- Vehicle management
- Vehicle CRUD operations
- Vehicle availability management
- Vehicle filtering
- Vehicle booking
- Booking validation
- Prevention of overlapping bookings
- Automatic booking price calculation
- Customer phone number validation
- Django REST Framework API
- HTML frontend interface
- Postman API testing


# Technologies Used

- Python
- Django
- Django REST Framework
- HTML
- CSS
- Bootstrap

- Postman
